# Registers

The structured registers supporting this assessment are maintained as CSV files in the repository. They provide traceability between source evidence, identified risks, proposed assurance activities, and recommendations.

## Source register

Records the source references used in the assessment.

[View or download the source register (CSV)](https://github.com/houda-benlemmouden/pidm2024-ai-assurance/blob/main/registers/source-register.csv)

## Risk register

Records the identified risks, evidence references, assessment fields, and outstanding uncertainties.

[View or download the risk register (CSV)](https://github.com/houda-benlemmouden/pidm2024-ai-assurance/blob/main/registers/risk-register.csv)

## Assurance test register

Lists the proposed assurance tests and their links to identified risks.

[View or download the assurance test register (CSV)](https://github.com/houda-benlemmouden/pidm2024-ai-assurance/blob/main/registers/assurance-test-register.csv)

## Recommendations register

Records proposed recommendations and their links to identified risks.

[View or download the recommendations register (CSV)](https://github.com/houda-benlemmouden/pidm2024-ai-assurance/blob/main/registers/recommendations-register.csv)

## Interpretation

These registers are supporting assessment artefacts, not evidence that the described system has been implemented or that any proposed test has been completed. The status and limitations recorded in each register should be considered alongside the final assessment report.
