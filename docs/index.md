# AI Governance & Assurance

**Independent assessment of AI-enabled public-safety capabilities**

PIDM2024 · Module #32 – Public Safety

---

## Assessment overview

This portfolio examines AI-related capabilities described in a public-sector technical procurement specification. It applies a structured, evidence-based approach to system understanding, risk identification, assurance planning, and recommendations.

The assessment distinguishes documented requirements from assumptions, implementation evidence, and matters that remain unverified.

## Assessment at a glance

| Area | Deliverable |
|---|---|
| Source analysis | Requirements baseline and evidence-gap register |
| System understanding | AI function inventory and system-context diagram |
| Risk assessment | 11 identified risks with documented evidence links |
| Assurance planning | 11 proposed assurance tests |
| Recommendations | 6 proposed actions linked to identified risks |
| Final reporting | Overall assessment, conclusions, and limitations |

## Scope and limitations

This is an independent, document-based assessment of the capabilities described in the technical specification. It is not an audit of a deployed system, a certification, or a demonstration of legal compliance.

The specification alone does not establish that the described capabilities have been implemented, that operational controls are effective, or that system performance has been verified. Assurance tests and recommendations in this portfolio are proposed activities, not completed tests or confirmed remediation.
